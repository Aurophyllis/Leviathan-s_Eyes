负责人 Luo。课设报告与 Windows 视频取证软件由 Luo 完成。课程任务书对组队人数的要求存在冲突，单人提交资格请尽早向任课教师确认，当前按 2026 年 12 月 23 日提交准备。

## 交付目标

- Windows 软件能打开本地视频、生成带时间戳和编号的拼图、回取清晰单帧。
- 本机 HTTP 接口和一个示例连接器能让具备视觉能力的 Agent 读取实际图像并按时间追看。最终验收包含一次可用原片核对的真实问答演示。
- XeLaTeX 报告正文不少于 4000 字。解释 AKS、FOCUS、K-frames 和 KFS-Bench，复现 AKS 与 FOCUS 的选帧核心，呈现自研方法、对照、消融和失败案例。

## Agent 开发说明

从 GitHub 仓库根目录工作。每次先检查现有改动，按一个可验收的功能提交代码和复现命令。用 GitHub 的提交或 PR 记录版本、自测日志和已知限制。样片和引用资源按[资源索引](README.md)核对。报告中的数据来自真实运行记录。

接口细化时沿用三项能力。查询当前视频，按时间区间请求一组观察，通过返回的格号或帧 ID 取回单帧。时间统一为距首个有效展示时间戳的毫秒，区间左闭右开。连接器将图片字节交给 Agent；验证记录应包含问题、模型、时间戳和答复。

dsh-see-now 的低分辨率变化分、切点、运动累积、兜底和拼图属于上游工作。课设验证固定帧预算下的时间锚点分配，以及总览后按需取回清晰帧的效果。参考源码和引用要求见[资源索引](README.md)。
